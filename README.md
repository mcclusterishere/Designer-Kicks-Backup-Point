# Designer Kicks / The Heat Chart — Development Backup

This repository is a context backup for **The Heat Chart** (https://theheatchart.com),
the custom-sneaker culture platform operated by **McCluster Corp** through its
**Equity Uprise** program. The live application and its full history live in the
`designer-kicks-platform` repository.

It preserves the development/context files used while building the platform so the
project's setup notes are never lost:

- **AGENTS.md** — build and convention notes for the customized Next.js version
  the platform runs on.
- **CLAUDE.md** — pointer that imports `AGENTS.md`.

For the complete application source, see the main repository.
